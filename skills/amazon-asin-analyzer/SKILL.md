# 亚马逊ASIN深度分析与消费者行为模拟

## 核心能力

本技能通过分析亚马逊产品页面，模拟真实消费者在Rufus AI助手场景下的决策过程，提供全面的产品洞察和优化建议。

## 工作流程

### 阶段1：ASIN信息抓取

1. **访问亚马逊产品页面**
   - 构造URL：`https://www.amazon.com/dp/{ASIN}` 或使用搜索
   - 提取页面核心信息：
     - 产品标题（Title）
     - 产品图片
     - 价格（Price）
     - 评分（Rating）和评论数（Reviews Count）
     - BSR排名（Best Sellers Rank）
     - 产品特性（Bullet Points）
     - 变体信息（Variations）
     - 库存状态（Availability）

2. **识别产品类别**
   - 根据标题和类目信息判断产品类型
   - 识别品牌、型号、规格
   - 判断目标用户群体

### 阶段2：5位消费者心理模拟

模拟5位具有不同背景的消费者角色，每位代表一类典型用户：

| 消费者角色 | 背景特征 | 核心关注点 |
|-----------|---------|-----------|
| **精打细算型** | 价格敏感，追求性价比 | 价格对比、保修政策、替代品 |
| **品质优先型** | 注重质量，愿意付溢价 | 材质认证、耐用性、品牌口碑 |
| **新手入门型** | 首次购买，缺乏经验 | 使用难度、配件清单、安全性 |
| **比价犹豫型** | 决策周期长，爱比较 | 与竞品差异、用户评价、优缺点 |
| **快速决策型** | 目的明确，不拖泥带水 | 核心参数、配送速度、库存 |

### 阶段3：Rufus问题生成与解答

为每位消费者生成他们可能问Rufus的3个核心问题：

**示例问题类型：**
- "这个和XXX品牌比怎么样？"
- "这个产品适合XXX场景使用吗？"
- "保修期是多久？"
- "包含哪些配件？"
- "尺寸/规格是怎样的？"
- "容易安装/使用吗？"
- "配送多久能到？"

**在页面中寻找答案：**
1. 在标题、特性、描述中搜索关键词
2. 检查图片中的规格信息
3. 查看Q&A区域（如果可获取）
4. 分析评论中的常见问题

### 阶段4：下单决策判断

基于页面信息，回答以下关键问题：

| 决策维度 | 评估标准 | 权重 |
|---------|---------|------|
| 信息完整性 | 是否有足够信息做决策？ | 25% |
| 价格合理性 | 价格是否匹配价值感知？ | 20% |
| 信任度建立 | 评分、评论、认证是否充分？ | 25% |
| 风险感知 | 退货政策、保修是否清晰？ | 15% |
| 紧急程度 | 是否有促销、库存紧张？ | 15% |

**输出格式：**
```
购买决策：[强烈推荐/推荐/中立/不推荐/强烈不推荐]
下单概率：[X]%
核心障碍：[描述主要阻碍因素]
```

### 阶段5：改进建议生成

从三个维度提供优化建议：

#### A. 信息完整度优化
- [ ] 标题优化：添加关键属性词
- [ ] 要点补充：覆盖用户决策信息盲点
- [ ] 图片优化：增加信息图/对比图/使用场景图

#### B. 信任度提升
- [ ] 评论管理策略
- [ ] A+内容优化建议
- [ ] 认证和保修突出展示

#### C. 转化率优化
- [ ] 价格策略建议
- [ ] 变体组合优化
- [ ] 促销和联动策略

## 质量标准

- 所有Rufus问题必须基于页面实际信息验证
- 找不到的信息必须明确标记
- 建议必须具体可执行
- 分析需要客观、数据驱动

## 常见ASIN格式识别

- 美国站：`B0XXXXXXX`（10位字母数字）
- 带国家前缀：`amzn.com/dp/B0XXXXXXX`
- URL格式：`https://www.amazon.com/dp/B0XXXXXXX`

## 错误处理

- ASIN格式无效：提示用户检查格式
- 页面无法访问：尝试备用URL或搜索方式
- 产品下架：提示产品可能已下架或库存不足
