# 成本估算锚点（Cost Anchors）

> 选品调研必备的"成本对标表"。2026 年 7 月行情，MOQ 100 件批量，海运 FOB Shenzhen。

---

## 通用成本公式

```
到岸成本（CIF + DDP）= 采购价 × (1 + 关税 7-12%) + FBA 头程 + 入仓费
售价（Amazon）       = 售价 USD
平台佣金              = 售价 × 15%（Health/Personal Care 类目）
广告成本              = 售价 × 15%（新品期，成熟期降到 8-10%）
退货预留              = 售价 × 5%（Health 类目平均退货率）
─────────────────────────────────────
净利润 = 售价 - 采购 - 关税 - FBA - 头程 - 平台佣金 - 广告 - 退货预留
净利润率 = 净利润 / 售价
```

## 1688 / Alibaba 询价话术模板

发给供应商的标准话术（中文）：

```
你好，我是亚马逊美国站卖家，准备做 {品名}。需要询价：

1. 100 件 / 500 件 / 1000 件 三个梯度的 FOB Shenzhen 价格
2. 主要规格：{列关键参数}
3. 是否提供 OEM / 包装定制？最小起订量？
4. 是否支持 FBA 头程发货（Amazon FBA Prep）？
5. 有哪些认证（FDA / FCC / CE / UL）？能否提供认证文件？
6. 是否曾被美国市场起诉或收到过律师函？特别是 22-cv-XXXX 系列案件？
7. 能否提供辐照度（mW/cm²）等技术参数的第三方测试报告？
8. 包装尺寸 / 单箱重量 / 装箱数量？

请提供 PDF 报价单 + 产品图片 + 视频。谢谢。
```

**关键问题**：
- 第 6 个问题直接问专利风险
- 第 7 个问题直接问技术参数（专业买家表现）
- 第 8 个问题算 FBA 费用必备

## 1688 平台采购风险提示

⚠️ **1688 价格 vs 真实采购价**：
- 1688 标价 = 单件散价
- 真实 100 件采购 = 1688 标价 × 0.6-0.8（量大优惠）
- 真实 500 件采购 = 1688 标价 × 0.4-0.6
- **Always 拿样品 + 至少 3 家比价**

⚠️ **隐藏成本**：
- 包装费（彩盒 vs 素盒差 $0.5-2/件）
- 标签贴（Amazon FNSKU + UPC）
- 头程运费（不是固定的，要看货代报价）
- 关税（Health 类 7-12%，普通电子 0-5%）

⚠️ **FBA 费用查表**：
- 用 Amazon FBA Calculator 精确算
- https://sellercentral.amazon.com/help/hub/reference/GTZNJZMY5V5YZQB9

## eBay 价差分析法（不查 1688 也能粗算）

当 1688 询价来不及做，可以用 eBay 同款 retail 价格反推：

```
eBay retail 价 = 售价 × 3-5（零售 vs 批发）
估算采购价    = eBay retail 价 / 3-5
估算净利润率   = (售价 - 估算采购价 - FBA) / 售价
```

**例**：
- eBay 同款卖 $40
- 估算采购价 = $40 / 4 = $10
- 假设售价 $60
- 估算净利润率 = ($60 - $10 - $7) / $60 = 72%
- **这个数字通常偏高**，要打折

**实操**：eBay 价格 / 5 = 保守的采购估算（含物流）

## 头部竞品毛利率反推

从公开数据反推头部竞品的毛利率：

**公式**：
```
假设头部 ASIN 售价 = $X
公开信息：BSR / 评论数 / 销量估算
类目平均采购价（按规格 + 1688）= $Y
FBA + 头程 = $Z
毛利率 ≈ (X - Y - Z) / X
```

**示例**：
- BestQool Red Light Belt 售价 $192
- 估算采购 $30-40（43W 220 LED 高端）
- FBA + 头程 $15
- 毛利率 ≈ ($192 - $35 - $15) / $192 ≈ 74%

如果头部竞品毛利率 > 70%，说明品类有溢价空间。
