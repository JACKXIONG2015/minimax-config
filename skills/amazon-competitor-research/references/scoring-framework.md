# 5 维度评分框架（Scoring Framework）

> 每维度 0-5 分，5 个维度加权得总分，4.0+ 强推，3.0-3.99 谨慎，< 3.0 不进。

---

## 维度 1：市场容量（权重 25%）

**评估内容**：这个品类的总需求够不够大，天花板在哪

| 分值 | 评估标准 |
|---|---|
| 5.0 | 大类 BSR < 1,000 / 头部月销 1 万+ / 趋势上升 |
| 4.0 | 大类 BSR 1k-10k / 头部月销 3k-1 万 / 趋势平稳 |
| 3.0 | 大类 BSR 10k-50k / 头部月销 1k-3k / 趋势平稳 |
| 2.0 | 大类 BSR 50k-100k / 头部月销 500-1k |
| 1.0 | 大类 BSR > 100k / 头部月销 < 500 |
| 0.0 | 类目无销量或被算法降权 |

**加分项**（最多 +0.5）：
- 季节性高峰明显（Q4 翻倍）
- 节日送礼属性强
- 复购率高（消耗品）

**减分项**（最多 -1.0）：
- 类目整体下降趋势
- 大卖家清场迹象
- Buy Box 普遍异常

---

## 维度 2：竞争格局（权重 25%）

**评估内容**：头部集中度、价格带分散度、新卖家进入难度

| 分值 | 评估标准 |
|---|---|
| 5.0 | Top 3 评论 < 500 / 价格带分散 / 新品进入容易 |
| 4.0 | Top 3 评论 500-2k / 价格带 3 段分散 / 进入难度低 |
| 3.0 | Top 3 评论 2k-5k / 价格带 2 段 / 进入难度中 |
| 2.0 | Top 3 评论 5k-10k / 价格带集中 / 进入难 |
| 1.0 | Top 3 评论 > 10k / 头部品牌锁定 / 进入难 |
| 0.0 | Amazon's Choice 头部垄断 / 品类被锁死 |

**加分项**：
- 存在明显价格断层（如 $30-40 主流但 $60-80 空白）
- 头部评论增长停滞
- Top 10 中出现新品牌

**减分项**：
- Amazon's Choice 被某品牌锁死
- 头部 3 个品牌占 60%+ 销量
- 价格战明显（同质化严重）

---

## 维度 3：利润空间（权重 20%）

**评估内容**：售价 - 采购 - FBA - 头程的净利润

**成本估算公式**：
```
到岸成本 = 采购价 + FBA 费用 + 头程 + 关税
净利润 = 售价 - 到岸成本 - 平台佣金(15%) - 广告(假设 15%)
净利润率 = 净利润 / 售价
```

| 分值 | 评估标准 |
|---|---|
| 5.0 | 净利润率 ≥ 50% |
| 4.0 | 净利润率 40-50% |
| 3.0 | 净利润率 30-40% |
| 2.0 | 净利润率 20-30% |
| 1.0 | 净利润率 10-20% |
| 0.0 | 净利润率 < 10% |

**计算锚点**（按 2026 年行情）：
- FBA 费用：标准件 $3-5 / 加大件 $6-10
- 头程：海运拼柜 $1-3/kg
- 平台佣金：15%（Health 类目）
- 广告：新品 15-25%，成熟 8-15%

**1688 询价锚点**：见 `cost-anchors.md`

## 维度 4：差异化机会（权重 20%）

**评估内容**：现有 listing 集体未满足的诉求 = 你的差异化卖点

**评分依据**：5 个画像 × 5 个 listing = 25 个"未找到"频次

| 分值 | 评估标准 |
|---|---|
| 5.0 | 5/5 listing 集体未满足 3+ 个核心诉求 |
| 4.0 | 4-5/5 listing 集体未满足 2-3 个核心诉求 |
| 3.0 | 3-4/5 listing 集体未满足 1-2 个核心诉求 |
| 2.0 | 2-3/5 listing 集体未满足 1 个核心诉求 |
| 1.0 | 集体未满足 < 1 个 |
| 0.0 | 全部 listing 都做得很全 |

**核心诉求定义**：
- "精打细算"维度未满足 = warranty / FSA / 价格对比 缺失
- "品质优先"维度未满足 = FDA / 功率密度 / 临床数据 缺失
- "新手入门"维度未满足 = 视频教程 / 配件清单 / 安全警告 缺失
- "比价犹豫"维度未满足 = 横向对比表 / 见效周期 缺失
- "快速决策"维度未满足 = Buy Box 异常 / 配送信息 / 退换货 缺失

**反向扣分**：
- 5/5 listing 都做到 = 没有差异化空间
- 集体满足但有 1 家做得特别好 = 对手护城河深

## 维度 5：进入壁垒（权重 10%）

**评估内容**：专利、品牌、认证、资金门槛

| 分值 | 评估标准 |
|---|---|
| 5.0 | 无专利 + 无品牌备案 + 无认证 + < $3k 启动 |
| 4.0 | 1 项专利可规避 + 1 项认证需做 + < $5k 启动 |
| 3.0 | 2 项专利 + 2 项认证 + < $8k 启动 |
| 2.0 | 3+ 项专利 + 3 项认证 + < $15k 启动 |
| 1.0 | 5+ 项专利 + 多项认证 + < $25k 启动 |
| 0.0 | 头部品牌备案锁死 + 专利布局深 + > $25k 启动 |

**专利检索要点**：
- USPTO / Google Patents 搜 `{品名} + wearable / belt / pad`
- 重点关注中国公司对美诉讼的 22-cv-XXXX 系列案件
- 详见 `patent-risk-checklist.md`

**品牌备案检查**：
- Amazon Brand Registry 2.0 搜索类目是否被锁
- USPTO Trademark 搜关键词

**认证清单**（按品类）：
- Health 类：FDA 510(k)（非强制但加分）、FSA/HSA、FCC
- 电子类：FCC、UL、ETL
- 美妆类：FDA cosmetic registration
- 儿童类：CPC、ASTM F963

## 加权计算示例

**示例 ASIN 评分**：
- 市场容量：4.0（BSR 5,000，月销 2k，趋势平稳）
- 竞争格局：3.5（Top 3 评论 3k，价格带 2 段，进入难度中）
- 利润空间：4.0（净利润率 45%）
- 差异化：4.5（4/5 listing 缺临床数据 + 2 项）
- 进入壁垒：4.0（1 项专利可规避，1 项认证待做）

**加权**：
```
总分 = 4.0×0.25 + 3.5×0.25 + 4.0×0.20 + 4.5×0.20 + 4.0×0.10
     = 1.00 + 0.875 + 0.80 + 0.90 + 0.40
     = 3.975
```

**决策**：3.975 → 🟡 谨慎进入（3.0-3.99 区间）

## 评分陷阱

1. **不要拍脑袋** — 每个分值必须有证据（BSR 数字、评论数、价格区间）
2. **不要打折** — Top 3 评论 3k 就是 3k，不要"差不多"
3. **不要忘记加权** — 总分 3.5 不等于"建议进入"，要看加权
4. **不要用平均值替代加权** — 各维度权重不同，简单平均会失真
5. **不要事后合理化** — 评分是为了决策，不是为了支持你已有的判断
